# Validation Sources

This document tracks outside sources used to validate the guidance in `Natural_Writing_Style_Guide.md`.

Validation standard:
- A section is considered validated when multiple credible sources broadly support the guidance.
- If one source disagrees, that is not enough by itself to force a change.
- If more than one credible source materially contradicts the guide, that contradiction should be reviewed before edits are made.
